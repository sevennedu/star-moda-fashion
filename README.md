# Star Moda Fashion — Landing page

Site estático (HTML, CSS e JS puros). Não precisa instalar nada: abra `index.html` no navegador
ou publique a pasta inteira em qualquer hospedagem (Netlify, Vercel, GitHub Pages, Hostinger…).

## Estrutura
- `index.html` — página completa, incluindo a fachada animada (SVG dentro da seção "Nossa loja").
- `css/styles.css` — cores da marca, layout e animações.
- `js/main.js` — WhatsApp, menu do celular, animações ao rolar e controle da fachada.
- `assets/img/` — fotos da loja otimizadas para a web.
- `assets/fachada-star-moda.svg` — ilustração simples da fachada (versão do protótipo).

## Informações da loja
- **WhatsApp:** (18) 98128-0955, configurado em `js/main.js` (`CONFIG`). Todos os botões usam esse valor.
- **Parcelamento:** até 10x sem juros, sem valor mínimo de parcela.
- **Depoimentos:** fictícios, aprovados pela loja.
- **Horário:** segunda a sexta, 9h às 18h; sábado, 9h às 13h.
- **Confirmar com a loja:** entrega do condicional em outras cidades.
